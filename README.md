# 🚗 Used Car Resale Value Analysis Dashboard

## Project Overview
This project explores the factors that influence used car resale prices and presents findings through an interactive Excel dashboard.

The dashboard helps identify pricing trends based on transmission type, mileage category, ownership history, car color, and model performance.

---

## Objectives
- Analyze average resale pricing across different categories  
- Identify high-value car models  
- Understand distribution across price bands  
- Provide an interactive dashboard for quick decision-making  

---

## Tools Used
- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers  
- KPI Cards  

---

## Dashboard Features

### KPI Summary
- **Average Resale Price:** $37.7k  
- **Highest Price:** $102k  
- **Total Listings:** 18  

### Interactive Filters
- Transmission Type  
- Owner Category  
- Car Color  

---

## Key Insights

### Transmission & Pricing
Automatic vehicles show higher resale values compared to manual cars.

### Popular Colors
White and black cars dominate the dataset, reflecting strong consumer preference.

### Price Band Distribution
Most cars fall within the mid-range category, with fewer budget and luxury listings.

### High-Value Models
Luxury models such as the Mercedes S-Class and Tesla Model 3 lead in resale pricing.
